SAMKHAN MARKET

Website statis untuk GitHub Pages.
- index.html: tampilan premium gelap/emas.
- Pilihan saham dan timeframe memuat ulang chart TradingView.
- Kalkulator pivot klasik dari OHLC yang dimasukkan manual.

Penting:
- Widget chart tidak menyediakan OHLC kepada kalkulator; input manual diperlukan.
- Data dan timeframe mengikuti ketersediaan TradingView dan bursa.
- Tidak ada API privat/berbayar, scraping, broker, atau auto-trading.
- Gratis hosting GitHub Pages, tetapi perlu internet untuk memuat chart.

Deploy:
1. Unggah index.html ke root repository GitHub.
2. Buka Settings > Pages.
3. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
4. Tunggu proses deploy selesai.
